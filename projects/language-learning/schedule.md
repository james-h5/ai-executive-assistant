# Language Learning Schedule

Monthly rotation — one language per month, cycling through all five, then repeating for reinforcement. Order sequences the Romance languages together (Spanish → Italian → French → Portuguese) so vocabulary transfers between them instead of causing confusion; German is unrelated (Germanic) and slots in at the end of each cycle.

| Month | Language | Notes |
|---|---|---|
| Aug 2026 | Spanish | Start here — anchor Romance language |
| Sep 2026 | Italian | — |
| Oct 2026 | French | — |
| Nov 2026 | Portuguese | Closest to Spanish — sequenced last among Romance languages to avoid early mixing |
| Dec 2026 | German | Unrelated to the others, no transfer risk |
| Jan 2027 | Spanish | Reinforcement cycle |
| Feb 2027 | Italian | Reinforcement cycle |
| Mar 2027 | French | Reinforcement cycle |
| Apr 2027 | Portuguese | Reinforcement cycle |
| May 2027 | German | Reinforcement cycle |

Rotation continues repeating in the same order (Spanish → Italian → French → Portuguese → German) after May 2027.

## Rationale
- 30 min/day × ~30 days = ~15 hours per language per month
- Two cycles through a language = ~30 hours = basic travel conversational ability
- Monthly gives enough depth to retain phrases before switching
- Sequencing the four Romance languages back-to-back (before German) lets skills compound instead of resetting each month
