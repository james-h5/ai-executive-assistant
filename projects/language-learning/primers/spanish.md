# Spanish Primer

## Pronunciation
- Vowels are always the same sound: a=ah, e=eh, i=ee, o=oh, u=oo
- `j` = a hard "h" sound (like clearing your throat lightly)
- `ll` = "y" sound (e.g. "llamo" = yah-mo)
- `ñ` = "ny" sound (e.g. "año" = ah-nyo)
- `rr` = rolled r
- `h` is always silent

## Numbers 1–20
uno, dos, tres, cuatro, cinco, seis, siete, ocho, nueve, diez, once, doce, trece, catorce, quince, dieciséis, diecisiete, dieciocho, diecinueve, veinte

## Core Grammar
- Nouns are gendered: masculine uses "el", feminine uses "la" (el libro, la mesa)
- Plurals: add "-s" (or "-es" if ending in a consonant)
- Verbs conjugate by who's doing the action (yo, tú, él/ella, nosotros, ellos) — three verb families: -ar, -er, -ir
- "Tú" is informal you, "usted" is formal/polite you — use "usted" with strangers/older people
