# Sheffield — Exhaustive Unit Match List

**Purpose:** unlike `sheffield.md` (which narrows down to a verified, realistic 4-unit lineup), this file is deliberately over-inclusive — every Sheffield module that relates to one of the 10 QUT units in some way, so nothing gets missed while options are still open. When in doubt, it's on the list.

**Source:** the real 2026/27 University of Sheffield Study Abroad & Exchange Modules Catalogue (Google Sheet, as of 26 May 2026), filtered to the three schools that cover James's units: **Electrical and Electronic Engineering** (51 undergrad modules), **Economics** (38), **Management** (49) — 138 modules screened in total.

**Scope note — this list includes Spring and Academic Year modules, not just Autumn.** A standard Sept–Jan exchange semester only reaches Autumn-semester modules (Academic Year modules can't be split, and Spring-only modules don't run in that window) — but per James's instruction to catch everything that relates "in some way," semester timing isn't used as a filter here. Each row shows its semester so timing can be applied later once semester-vs-year is decided.

**Access flags:** "Subj" = available to subject-only exchange students; "Uni-wide" = available to university-wide exchange students (the category James needs, since he wants a mixed Engineering + Finance course load — confirmed in `sheffield.md`). A **No** under Uni-wide means that module is realistically closed to James unless the exchange type changes.

## Caveats — read before acting on this list

1. **This is a brainstorm, not a filtered recommendation** — `sheffield.md` remains the verified, realistic pick. Cross-reference before committing to anything here as an actual application choice.
2. **Uni-wide No means realistically inaccessible** for James's mixed-subject exchange, per the reasoning already confirmed in `sheffield.md`. A lot of the strongest Electromagnetics/Machines and Energy Supply matches carry this flag.
3. **Spring and Academic Year modules only work if the exchange covers that period.** A standard Sept–Jan single semester only reaches Autumn modules; Academic Year modules can't be split; Spring-only modules (including the MGT375 and MGT230 finds above) would need either a full-year exchange or a Spring-start exchange — neither of which is confirmed. See `../README.md` "Next Steps" for the semester-vs-year decision still in flight.
4. **"Loose" matches are genuinely loose** — several (MGT3012, ECN21005/ECN31002, MGT3005) share a theme with the QUT unit rather than overlapping content. Included per the "if in doubt, add it" brief, not because they're strong candidates.
5. **Credits haven't been converted to QUT cp** for anything on this list — do that once a real shortlist is drawn from it (2 Sheffield credits = 1 ECTS; QUT ratio is 12cp = 15 UK credits per `degree-plan-notes.md`).
